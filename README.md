# 全国大学生数学竞赛 · 非数学专业 A 类（初赛）

> 目标：只围绕初赛高等数学建立可持续维护的 GitHub 复习仓库。

## 仓库结构

- `00-备考总览`：使用说明、复习节奏、做题规范
- `01-函数极限与连续`
- `02-一元微分学`
- `03-一元积分学`
- `04-常微分方程`
- `05-向量与空间解析几何`
- `06-多元函数微分学`
- `07-重积分`
- `08-曲线积分与曲面积分`
- `09-无穷级数`
- `错题本`：统一复盘模板
- `模拟训练`：后期放整套限时训练

每个知识板块都包含：

1. `README.md`：核心知识框架与竞赛侧重点
2. `综合练习.md`：1 道原创综合大题
3. `参考解答.md`：完整思路与关键步骤

## 建议使用方式

第一轮以“知识框架 → 例题 → 综合练习”为主；第二轮把每章错题整理到 `错题本`；第三轮开始按 150 分钟进行整卷训练。

做综合题时建议先只打开 `综合练习.md`，独立完成后再看 `参考解答.md`。
