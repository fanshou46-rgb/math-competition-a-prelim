# 备考总览

## 第一阶段：知识补全

按 01 → 09 的顺序推进。每章至少完成：定义、核心定理、常用技巧、综合练习。

## 第二阶段：专题强化

优先强化以下高频能力：

- 极限中的等价无穷小、Taylor 展开与洛必达
- 中值定理、单调性、极值、最值、不等式证明
- 换元积分、分部积分、反常积分
- 多元极值、重积分坐标变换
- Green / Gauss / Stokes 思想
- 数项级数与幂级数的判敛、求和

## 第三阶段：真题与限时训练

每套题完成后只记录三类问题：

1. 不会：知识点缺失
2. 会但慢：方法不熟
3. 会且错：计算或条件检查失误

不要把错题本写成答案抄写本，要写“为什么当时没想到”。
